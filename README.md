## Overview

**Stream Speeder**は、Netflix, Prime Video で再生速度を調整できます｡

## Features

| Key | Speed |
| :-: | ----: |
|  ;  | 0.25- |
|  '  | 0.25+ |
|  [  |  0.5- |
|  ]  |  0.5+ |
|  -  |    1- |
|  =  |    1+ |
|  `  |  0.5x |
|  1  |    1x |
|  2  |    2x |
|  3  |    3x |
|  4  |    4x |
